Game-HD2D-Enhancer 0.1.0 alpha（Windows x64 测试版）
==================================================
这是首次集成测试版，不是已完成全部游戏兼容验证的正式版。

运行要求
--------
优先 Windows 11 64 位；最低目标 Windows 10 2004 / build 19041。
显卡需要 Direct3D 11 feature level 11_0。运行不需要 Python、Visual Studio、Codex、Work 或联网。
本版只处理 SDR；建议测试时关闭 Windows HDR / Auto HDR。不要关闭防病毒或其他系统安全功能。
完整解压 ZIP 后双击 Game-HD2D-Enhancer.exe。不要只移动 EXE：shaders/NIS 与 licenses 必须一起保留。

先用测试画面验证
----------------
1. 打开 Game-HD2D-Enhancer.exe，点击“打开测试画面”。
2. 测试画面是另一个独立进程，里面有色块、移动方块和鼠标/按键计数。
3. 点击测试画面，使它成为前台窗口，再按 Ctrl + Alt + H。
4. 确认画面等比例放大、没有拖影式套娃；点击和按键计数应增加。
5. 按 Ctrl + Alt + End 停止增强，测试画面应继续独立运行。
6. 再测试真实游戏。测试画面验证不等于实际游戏已经兼容。

用于吞食天地或模拟器
--------------------
先正常打开游戏，优先用窗口模式。不需要添加 EXE、不需要建立游戏库。
在增强器点击“刷新窗口”，选择真正显示游戏画面的窗口，再点击“戴上眼镜 / 开启”。
天马G是前端：选择它实际启动的模拟器窗口，不是封面列表窗口。
快捷键 Ctrl + Alt + H 直接选择当前前台窗口并开启；增强中再次按下则停止。
Ctrl + Alt + End 是紧急停止，不会向游戏发送退出命令。

已有的实时处理路径
------------------
- Windows Graphics Capture 指定窗口捕获，D3D11 GPU 纹理处理。
- 原味像素：尽可能用整数倍；输出小于源图时使用等比例最近邻缩小并提示。
- NIS：实际调用 NVIDIA Image Scaling v1.0.3 shader，默认锐化 20%。NIS 已带锐化，不再叠加第二次锐化。
- 比例超过 NIS 支持的 2 倍范围时，先最近邻整数预放大，再执行 NIS。
- 输出小于源图时，NIS 模式使用双线性缩小并提示；不冒称 NIS 正在执行。
- 双线性：用于兼容测试与原画对照。
- 30 / 60 FPS 呈现上限。不做插帧，不把呈现 FPS 当作游戏 FPS 或延迟。
- 全屏按比例留黑边，不拉伸。800×600 在 1920×1080 屏幕上的最大等比例内容区是 1440×1080。

输入与兼容边界（请务必读）
--------------------------
全屏鼠标映射是实验功能，通过普通 Win32 鼠标消息转发到原游戏/子窗口；不是万能输入穿透。
适用于处理普通鼠标消息的窗口。不保证兼容 Raw Input、DirectInput、GetCursorPos 定位的游戏、特殊光标、鼠标侧键、复杂拖拽、触控手势、菜单或反作弊游戏。
键盘/手柄输入继续由前台原游戏接收；本程序不模拟手柄。真实手柄/触摸兼容尚待设备测试。
切换到其他前台窗口、源窗口最小化或关闭时，全屏增强停止。关闭预览窗口只关闭增强。
独立预览模式不会把鼠标转发给游戏，继续操作原游戏窗口即可。
鼠标不正确时先按 Ctrl+Alt+End 停止，再切换“独立预览窗口”；不要在失效状态继续重要操作。
游戏和增强器权限不同可能导致输入转发失败。程序不自动提权，不绕过系统权限。
本版可能保留系统黄色捕获边框；没有申请无边框捕获权限。
不支持独占全屏或受保护的窗口时，应停止并提示，不注入游戏、不绕过保护。
最小化游戏后不能承诺仍能捕获。普通窗口被增强画面盖住后的兼容性要逐游戏验证。

不会做的事
----------
不修改 EXE、DLL、游戏资源或存档；不向游戏发送结束进程命令。
不录屏、不保存真实捕获帧、不自动截图、不生成视频缓存、不上传画面。
只使用有界帧池和可重复使用的显存纹理。系统/驱动自己的缓存不等于程序录屏。
不包含 DLSS5，不调用 Codex / Work / 其他 AI 服务。
不全局修改鼠标指针、不锁住系统鼠标、不修改系统注册表。

测试状态
--------
构建任务运行 CPU 几何测试和 Direct3D11 WARP 软件渲染正确性测试，包括真实 NIS shader。
测试结果随构建包附带。通过这些测试不等于 WGC 已在所有桌面环境成功，也不等于吞食天地或掌机实测通过。
真实捕获、鼠标、手柄、中文文字效果、反复启停、性能、耗电与续航仍需实机测试。
本版未签名，可能被 Windows 标为未知发布者；应核对来源/哈希，不要为测试关闭系统防护。
